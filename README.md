# Tailora — build

Qui ci sono solo le versioni pronte da installare di Tailora (il codice è in un repository privato). L'app controlla l'ultima release di questo repository per avvisare quando c'è un aggiornamento.

Scarica dalla pagina [Releases](../../releases/latest):

- **Android**: `TakeMyMeasures-vX.Y.Z-android.apk` (consenti l'installazione da origini sconosciute)
- **macOS**: `TakeMyMeasures-vX.Y.Z-macos.zip` (app non firmata: al primo avvio tasto destro → Apri)
- **Windows**: `TakeMyMeasures-vX.Y.Z-windows.zip` (estrai e avvia `take_my_measures.exe`)
